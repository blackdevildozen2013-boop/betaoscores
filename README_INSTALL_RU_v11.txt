Установка на GitHub:
1. Распакуйте архив на Mac.
2. Откройте корень репозитория сайта.
3. Загрузите файлы и папки из архива с сохранением путей. Не загружайте ZIP как один файл.
4. Убедитесь, что в корне обновились index.html, match-center.html и файлы CSS/JS.
5. Папку scripts сохраняйте с её внутренним путём. Текущие папки data и .github на GitHub НЕ удаляйте и НЕ перезаписывайте.
6. Дождитесь успешной публикации GitHub Pages и откройте сайт с обновлением кэша (Cmd+Shift+R).

Важно:
• Футбольная лаборатория использует демонстрационные данные. Проценты — модельные оценки, не реальные коэффициенты.
• Существующие данные API не изменяются.
• На опубликованном сайте работоспособность необходимо проверить после загрузки.
• Анимации автоматически отключаются для устройств с настройкой Reduced Motion.
