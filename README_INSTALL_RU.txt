BETTAO MATCH CENTER — ЕДИНЫЙ ПАКЕТ ОБНОВЛЕНИЙ (v8)

В одном архиве собраны ВСЕ обновления Match Center из v4, v5, v6 и v7:
- премиальный аналитический интерфейс и Football Lab с демонстрационными данными;
- вероятности, ожидаемые голы, форма, история и сценарии;
- визуальные эффекты и автоматические 3D flip-карточки;
- определение языка браузера и ручной выбор из 9 языков;
- накопление истории результатов при последующих обновлениях API.

  scripts/fetch_matches.py

Как установить:
1. Распакуйте этот архив на Mac.
2. Загрузите ШЕСТЬ файлов из корня архива в КОРЕНЬ репозитория GitHub.
3. Отдельно откройте папку scripts/ в репозитории и замените fetch_matches.py файлом из scripts/ архива.
4. Нажмите Commit changes. Дождитесь обновления GitHub Pages и перезагрузите сайт.
5. Не загружайте README в GitHub, если он не нужен.

ВАЖНО:
- Это пакет изменённых файлов, а не замена всего репозитория. Остальные файлы сайта оставьте как есть.
- Новые API-данные не появляются сами по себе: история пополняется по мере запусков workflow.
- Football Lab и его вероятности — демонстрационная развлекательная модельная демонстрация, не фактические прогнозы.
- Локализация охватывает основные элементы Match Center, но не все страницы сайта и не весь текст.
- API-ключ и секреты в архив не включены.
- Синтаксис JS и Python проверен; реальная публикация на GitHub Pages ещё не проверялась.
